# Final Activity #2 – Employee Payroll System Using Inner Class and Scanner

## Objective

Create a Java program that demonstrates the use of:

- Outer Class
- Inner Class
- Scanner Class
- User Input
- Methods and Variables
- Conditional Statements

## Instructions

1. Create an outer class named `Employee_LastName`.
2. Inside the outer class, declare the following variables:
   - `employeeName_LastName`
   - `position_LastName`
   - `department_LastName`
3. Create an inner class named `Salary_LastName`.
4. Inside the `Salary` class:
   - Ask the user to enter:
     - Number of hours worked
     - Rate per hour
   - Compute the gross salary.

### Formula

```
Gross Salary = Hours Worked × Rate per Hour
```

5. Create a separate method that determines the employee salary status based on the gross salary:

| Status | Range |
|--------|-------|
| High Salary | ₱30,000 and above |
| Average Salary | ₱15,000 – ₱29,999 |
| Low Salary | Below ₱15,000 |

> The salary status method must return a `String`.

## Program Requirements

Your program must:

1. Use an Outer Class and Inner Class
2. Use `Scanner` for input
3. Accept employee information from the user
4. Compute the gross salary
5. Display complete employee details
6. Display the salary status
7. Use conditional statements
8. Create a separate method for salary status
9. The salary status method must return a `String`
10. Include proper output labels
11. Add your `Lastname` in:
    - Class names
    - Variable names
    - Method names
